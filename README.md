# satul-cernita
Site-ul satului Cernița – Florești  Acest site a fost creat de Bogdan Pirojoc pentru a prezenta satul Cernița din raionul Florești. Aici pot fi găsite informații despre istoria satului, populație, primărie, grădiniță, oficiul poștal și alte instituții. Scopul site-ului este de a promova frumusețea și valorile localității Cernița.
